# entrega/ — LaTeX dos relatórios

`latex_relatorios.zip` tem o código LaTeX do relatório final e do documento da Etapa 1, cada um numa pasta que compila
sozinha (com as figuras, os diagramas, a bibliografia e o template SBC). Dá para abrir direto no Overleaf com
*New Project > Upload Project*. Os mesmos arquivos estão soltos em [`relatorio/`](../relatorio) e
[`docs/etapa1/`](../docs/etapa1).
